# Product

## Register

product

## Users

Obsidian users who use Bases to select and organize notes, then need a spatial working surface for arranging those results, seeing relationships, and producing reusable JSON Canvas snapshots. Some users also use TaskNotes, but Canvas Bases must remain useful and understandable without it.

## Product Purpose

Canvas Bases adds spatial layout and direct manipulation to an existing Bases result set without replacing Bases as the source of truth. Success means users can move between query configuration, visual arrangement, note editing, relationship work, and Canvas export without losing data or fighting the interface.

## Brand Personality

Native, focused, dependable. The interface should feel like a compact Obsidian tool that recedes behind the board rather than a separate branded application.

## Anti-references

Avoid dashboard-style chrome, oversized persistent controls, decorative panels, unfamiliar form controls, and styling that competes with Obsidian themes. Do not make embedded or narrow views feel like a squeezed desktop layout.

## Design Principles

- Keep the board primary; controls should remain discoverable without covering its content.
- Follow Obsidian's interaction and theme conventions instead of inventing a parallel component system.
- Adapt structurally to embedded and narrow panes, with compact controls and preserved access to every action.
- Make destructive and data-writing actions explicit, while keeping routine navigation and layout actions lightweight.
- Degrade optional TaskNotes and mdbase capabilities cleanly without leaving broken or unexplained controls.

## Accessibility & Inclusion

Use semantic controls, keyboard-visible focus, tooltips or accessible names for icon-only actions, theme-compatible contrast, touch-usable targets, reduced-motion-friendly transitions, and layouts that remain operable in narrow panes and at increased interface zoom.
